# LostArk 모작 — 플레이어 전투

마우스로 목표 위치를 지정하고 여러 마법 스킬을 사용하는 아이소메트릭 액션 프로젝트입니다. 저는 **플레이어 조작·스킬·피격 상태와 전투 UI**를 담당했습니다. 하우징·보스 패턴·전체 시네마틱은 팀 결과로 구분합니다.

개발 기록은 저장된 변경 이력의 범위이며 정확한 전체 제작 일정과 동일한 의미는 아닙니다.

## 상세 페이지에서 다루는 기능

- 마우스 방향 회전·위치 지정 공격과 이동·회피 입력
- 블레이즈, 아이스 애로우, 종말의 날, 천벌, 익스플로전, 리액트, 돌풍
- 스킬별 쿨타임, 캐스팅 진행·취소, 애니메이션·효과 연동
- HP와 피격·경직·사망, 피해 수치와 전투 UI
- 팀 보스의 공격·카운터·그로기 구조와 플레이어 연동 지점
- 팀 하우징의 오브젝트 선택·배치·회전·이동·삭제와 결과 장면 전달
- 실제 변경 이력으로 확인한 수정 과정과 원본 파일 안내

## 역할 구분

| 본인 담당 | 팀 구현·공통 결과 |
|---|---|
| `BP_Player`, 스킬 액터, `BPC_Stats`, 플레이어 UMG 중심 작업 | C++ `ABoss`·`UBossFSM`과 보스 애니메이션·패턴 |
| 스킬 입력·쿨타임·캐스팅·피격·사망 처리 보완 | 하우징 C++와 배치 오브젝트·선택 UI |
| HP·피해 표시와 사운드·VFX 연동 | 맵, 보스·하우징·결과 장면이 연결된 전체 시연 |

플레이어 영역에도 팀원의 충돌 수정·통합 이력이 있습니다. 폴더 전체나 외부 그래픽·음원·애니메이션 자산을 단독 제작한 것으로 소개하지 않습니다.

## 확인 기준

기존 영상·역할 기록에 더해 원본 C++·설정, Blueprint에 저장된 함수·속성·자산 참조, Git 변경 이력을 확인했습니다. Blueprint의 모든 실행 연결을 재구성하거나 최신 프로젝트를 빌드·플레이 테스트한 결과는 아닙니다.

Lost Ark를 참고한 학습용 모작이며 공식 제품·제휴 프로젝트가 아닙니다. 원본 프로젝트와 제3자 에셋은 이 문서 저장소에 포함하지 않습니다.
