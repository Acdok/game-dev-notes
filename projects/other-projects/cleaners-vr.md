아래는 기존 영상 중심 요약입니다. 새 상세 페이지에는 오브젝트 선택·배치, 회전·삭제, 충돌·머티리얼, 저장 요소와 팀 VR·세척 기반을 구분해 정리했습니다.

![청소부들 VR 플레이 장면](../../assets/other-projects/vr_gameplay.jpg)

*VR 작업 공간의 팀 시연 화면입니다. 오브젝트 선택·배치는 본인 담당이며, 세척 시스템과 전체 진행 UI는 팀 결과입니다.*

## 개요

VR 포인터로 작업 대상과 가구를 선택해 공간에 배치하고, 차량 세척과 체크리스트를 따라 작업을 진행하는 VR 프로토타입입니다.

## 역할

과거 기여 기록에서 확인되는 본인 역할은 **오브젝트 배치 담당**입니다.

- VR 포인터로 차량·의자·테이블·파라솔을 선택하는 흐름
- 선택한 오브젝트를 작업 공간에 배치하는 흐름

## 영상에서 확인되는 기능

| 기능 | 기여 구분 |
|---|---|
| VR 포인터 기반 오브젝트 선택 UI | 본인 담당 범위가 포함된 장면 |
| 차량·가구의 작업 공간 배치 | 본인 담당 |
| 차량 표면 세척 | 팀 결과 |
| 체크리스트와 완료 시간 표시 | 팀 결과 |

## 근거와 한계

- 공개 근거: 위 시연 영상과 과거 포트폴리오의 `오브젝트 배치 담당` 기록
- 원본 C++·Blueprint 자산 정보와 Git 이력 분석은 위 상세 페이지에 보강했습니다. 전체 Blueprint 실행 그래프와 실기기 동작은 재검증하지 않았습니다.
- 세척 시스템 전체와 체크리스트 UI를 본인 단독 구현으로 표현하지 않습니다.
- 기기별 성능, 멀미·사용성 평가와 정량 테스트 결과는 확인되지 않았습니다.
