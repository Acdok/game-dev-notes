# Dopamin Survivor

> 뱀파이어 서바이벌류의 자동 전투·성장 구조에, 혈사포와 다중 발사·유도·분열의 조합을 더한 Unity 2D 생존 슈터

![적 사이로 휘어지는 혈사포 실행 장면](../../assets/dopamin-survivor/brimstone.jpg)

단순히 공격력을 올리는 대신, 획득한 아이템에 따라 **공격의 수·배치·경로·명중 후 동작**이 달라지는 프로토타입입니다. The Binding of Isaac의 혈사포(Brimstone)와 아이템 조합에서 착안해, 일반 탄환과 레이저에 공통으로 적용되는 공격 변형 구조를 구성했습니다. 원작의 모든 조합을 그대로 재현한 프로젝트는 아닙니다.

| 항목 | 내용 |
|---|---|
| 장르 | 2D 탑뷰 생존 슈터 · 자동 전투 · 아이템 빌드 |
| 개발 환경 | Unity 6.4 (`6000.4.10f1`), C#, 2D Physics, uGUI, LineRenderer |
| 개발 방식 | AI 보조 개발(바이브코딩) |
| 주요 기능 | 자동 조준·발사, 경험치·레벨업, 3지선다 보상, 아이템·세트 UI, 혈사포 조합 |
| 문서 근거 | 프로젝트 C# 코드·Task·체크리스트와 제공된 실행 녹화 |
| 현재 범위 | 프로토타입. 기록 영상은 Unity Editor 실행 화면 |

## 핵심 볼거리

- **혈사포 × 다중 발사:** 더블샷은 평행 2줄, 트리플·쿼드샷은 부채꼴 3·4줄로 공격 형태를 바꿉니다.
- **혈사포 × 유도:** 선택한 적의 위치를 따라 곡선 경로를 만들고, 그 경로를 렌더링과 피해 판정에 사용합니다.
- **혈사포 × 분열:** 명중 위치에서 작은 자식 레이저가 갈라집니다. 자식의 재분열을 막아 무한 증식을 방지합니다.
- **유도 효과의 구분:** 과충전 사격 세트의 유도는 부모 혈사포에 적용하고, 유도 칩을 획득하면 분열 레이저에도 유도를 전달합니다.
- **빌드 구성:** 아이템 개별 레벨과 세트의 서로 다른 아이템 수를 구분해, 중복 강화와 조합 완성을 별도로 처리합니다.

## 개발 방식과 설명 범위

Unity와 바이브코딩으로 제작한 프로젝트입니다. 프로젝트에 남아 있는 기획 문서·작업 명세·구현 체크리스트를 코드와 대조해 설명했습니다. 모든 코드를 수작업으로 작성했다거나, 화면의 아트 자산을 직접 제작했다는 의미는 아닙니다.

영상에서 확인한 화면과 코드에 구현된 조합을 구분했으며, 모든 조합의 실행 검증이나 성능 측정을 완료했다고 주장하지 않습니다. 원본 녹화와 프로젝트 전체는 배포하지 않고, 게임 영역을 잘라낸 캡처와 설명 문서만 공개합니다.
